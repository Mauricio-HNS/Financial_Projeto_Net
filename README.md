# FinTec .NET — Financial Domain Project

A .NET project focused on financial-domain concepts, application services and business operations.

## Project history

This repository represents an earlier stage of my evolution with .NET architecture and domain-oriented application design.

It is intentionally preserved as part of that history. The objective is not to make an old project look like it was originally built with today's architecture, but to document what the project demonstrates and keep the implementation maintainable.

## What this project demonstrates

- C# / .NET
- Domain-oriented organization
- Application services
- Financial business operations
- Separation between application/domain concerns
- Service-based business workflows

## Architecture

The solution contains separate areas for domain/application behavior and service operations. It was an important step toward the architectural practices used in later projects.

## Maintenance

Obvious incomplete operations and repository hygiene issues are being corrected without rewriting the project from scratch.

The project currently uses an older .NET target and should be considered a legacy project. Framework modernization should be performed as a controlled migration, with dependency compatibility and automated tests verified before changing runtime behavior.
